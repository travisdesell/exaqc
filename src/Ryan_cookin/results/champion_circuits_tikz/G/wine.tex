% D=13 features, N=6 qubits, K=3 classes. enc_gates=6, ansatz_gates=4, test_acc=0.861. Stage G enforces a two-block structure at qnode level: every encoder gate (blue, left) fires before any ansatz gate (orange, right). All parameters in both blocks are co-trained in a single Adam loop with backprop through the whole circuit, so the encoder learns a projection that helps the ansatz classify, and the ansatz learns to classify what the encoder produces. Same gate vocabulary as Stage F v2; the only thing that changed is the execution order.
